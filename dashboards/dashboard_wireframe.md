# Dashboard Wireframe

## Dashboard Title

Hotel Demand Analytics and Cancellation Dashboard

## Dashboard Objective

This dashboard will help hotel management understand booking demand, cancellation risk, revenue patterns, and customer segment behavior.

---

# Page 1: Executive Overview

## KPIs

- Total Bookings
- Cancellation Rate
- Average ADR
- Average Lead Time
- Total Room Nights
- Average Guests per Booking

## Visuals

- Bookings by Hotel Type
- Cancellation Rate by Hotel Type
- Monthly Booking Trend
- Top 10 Countries by Bookings

---

# Page 2: Cancellation Analysis

## Business Question

Which factors contribute most to booking cancellations?

## Filters

- Hotel Type
- Month
- Market Segment
- Customer Type
- Deposit Type

## Visuals

- Cancellation Rate by Hotel Type
- Cancellation Rate by Market Segment
- Cancellation Rate by Customer Type
- Cancellation Rate by Deposit Type
- Lead Time vs Cancellation

---

# Page 3: Revenue and ADR Analysis

## Business Question

How does average daily rate vary across hotel type, month, customer type, and stay length?

## KPIs

- Average ADR
- ADR by Hotel Type
- ADR by Customer Type
- ADR by Month

## Visuals

- ADR by Hotel Type
- ADR by Customer Type
- Monthly ADR Trend
- ADR by Stay Type

---

# Page 4: Customer Segment Analysis

## Business Question

Which customer groups are more valuable and reliable?

## Visuals

- Customer Type Distribution
- Customer Type vs Cancellation Rate
- Market Segment vs Cancellation Rate
- Average ADR by Customer Type
- Average Guests by Customer Type

---

# Recommended Filters
